# 원본 데이터 계약

원본은 용량과 재배포 조건 때문에 저장소에 커밋하지 않습니다. 개인식별정보와 API 키를
저장하지 않고, 제공기관에서 받은 ZIP·CSV를 수정하지 않은 상태로 보관합니다.

## 입력 자료

- 주민등록인구 CSV: 2014~2025년 연도별 `계`, 1세 단위, 전국 전체 시군구 현황
- HIRA ZIP: `전국 병의원 및 약국 현황 2025.12.zip`
- SGIS ZIP: `국가데이터처_SGIS 행정구역 통계 및 경계_20250630.zip`

## 처리 산출물

- `historical_population.csv`: 시군·연도별 총인구, 고령인구, 청년인구
- `hospitals.csv`: 의료기관 ID·종별·좌표·병상과 폐업 분석 대상 여부
- `demand_points.csv`: 행정동 인구·고령인구와 중심점
- `medical_supply.csv`: 시군별 병원급 기관 수·병상·인구가중 접근거리
- `regions.geojson`: 현재 전국 229개 시·군·자치구 경계
- `region_lookup.csv`: 현재 주민등록 시군구 코드·지역명·시도명

인구와 경계는 서로 다른 코드 체계를 사용하므로 `etl.py`에서 현재 주민등록 코드를 기준으로
동적 정합합니다. 도(道)의 일반시는 하위 구를 시 단위로 합산하고, 군위군 편입과 미추홀구
개명은 현재 코드로 연결합니다.
